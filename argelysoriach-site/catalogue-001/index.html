This is the first entry in the Seven Eighty Three catalogue. Seven Eighty Three is an independent digital systems and creative laboratory. We begin with its architect, because it is the one case we can audit completely. Wild-Lake, the artists agency, is built on the same system.

01 / Manifesto

The Architecture of an Empire.

  • We built it ourselves.
  • No studio budget. No permission. A vision and tools.
  • An empire is a set of systems that hold each other up. We use the word on purpose.
  • Seven Eighty Three is the laboratory. It holds the logic.
  • Wild-Lake is the agency built on it. It holds the artists.
  • The writing is the proof. It holds the weight.
  • Nothing here waited on funding, an institution, or a gatekeeper.
  • This catalogue starts with our own system, because it is the one we can measure.

02 / Method

One method. Two outputs.

The same hand builds the system and makes the work. That is the hybrid. The system gives the work a place to stand. The work gives the system a reason.

Systems

The backend.

  • Seven Eighty Three. An independent digital systems and creative laboratory.
  • Wild-Lake. The artists agency, built on Seven Eighty Three.
  • Infrastructure. Static HTML on Cloudflare. JSON-LD schema is the primary interface. The visual layer comes second.
  • Universe API. The framework. Six baseline rules:
    1. Closed-loop systems
    2. Sovereign logic
    3. Asset-based leverage
    4. First-principles engineering
    5. Organic, unforced growth
    6. Infrastructure that compounds, not extracts

Output

The work.

  • Writing. Autofiction and poetry. This Is Not a Love Story (Yankees) is Dispatch 01.
  • Brand platforms. Four, 2025 to 2026.
  • Concepts. A rebrand for Banana Republic, October 2026. Independent. Not affiliated with Banana Republic or Gap Inc.
  • Type and motion. Wordmarks, letterforms, and systems that move.

Process

The scouting method.

  1. Scout.
  2. Find what is broken.
  3. Make the smallest change with the most effect.
  4. Show it.
  5. Then build the site.

04 / Standard

The baseline.

Everything above is the standard. Every entry in the catalogue is measured against it.

Systems come in through Seven Eighty Three. Artists come in through Wild-Lake. Each artist gets the same four things, built the same way.

  1. Identity. One name. One mark. One voice.
  2. Site. Static, fast, and owned by the artist.
  3. Schema. A machine-readable layer that says who the artist is and what the work is.
  4. Archive. The work, dated and versioned.
