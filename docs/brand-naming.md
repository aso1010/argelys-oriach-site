# Wild-Lake naming

- Use **Wild-Lake** in public-facing copy, navigation, headings, link labels and descriptions.
- The formal organization name is **Wild Lake Studio**.
- Organization structured data uses `name: "Wild-Lake"` and `legalName: "Wild Lake Studio"` to connect the public and formal names.
- Preserve existing organization entity IDs when updating metadata; a display-name change must not create a second organization entity.
- Do not replace the public-facing brand with “Wild Lake,” “Wildlake,” or “Wild-Lake Studio.” The domain spelling is separate from the brand name.
